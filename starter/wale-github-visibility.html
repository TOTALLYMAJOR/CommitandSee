Coverage limits

GitHub repository metadata, selected refs, open PRs and Actions workflow runs are collected. Local-only commits and worktrees, issues, package/runtime dependencies, external CI, branch protection, artifact digests, production deployments, and human acceptance are not collected. Exact-SHA CI observations do not establish cross-repository compatibility. Source freshness is measured at collection time; test execution dates are shown separately. Provenance and snapshot contents are not cryptographically authenticated.
