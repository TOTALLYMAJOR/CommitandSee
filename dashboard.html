    Committed history

    Each repository uses its selected ref. Commit and line charts use non-merge commits reachable from that ref, grouped by commit time in the displayed timezone. They measure recorded churn, not total source-code size or product completion. Binary changes have no numeric LOC. Shallow, truncated, or unavailable history remains marked as partial.

    Filtering the history window changes the charts and their totals. Current worktree, branch, and stash observations stay current to the snapshot.

    Pending work

    Ahead / behind comparisons use locally cached upstream refs. Remote branches shown here are cached refs too; the dashboard does not fetch, push, or merge. Branch integration is an ancestry check against the selected ref. Squash or rebase merges, cherry-picks, and PR state need separate interpretation.

    Worktree LOC shows the tracked HEAD-to-working-tree delta. Staged and unstaged counts are separate and are not added together. Untracked files are listed separately. Branch-tip age and first observation time are clues for review, not proof that work was forgotten.
